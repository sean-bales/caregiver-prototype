Caregiver, the family app

Proposed changes to the Caregiver app

I reorganized the app so daily updates and actions are on the home screen, and related features are grouped together. The phone and desktop prototypes show the proposed screens.

Phone prototype Desktop prototype All prototype screens

What changed

Related features are grouped into four tabs

Today contains daily updates and actions. Story contains chapters, photos, and memories. Profile holds information about the person receiving care. Settings contains device and account options.

Current pageHome
The home screen prioritizes daily care

The home screen should show what matters most to the user when they open the app. Today brings replies, reminders and their outcomes, and device status together. The current home screen emphasizes memoir progress; the prototype removes the progress bar and keeps chapters in Story.

Current pageNotes
Messages and device controls are accessible from Today

Notes currently combines sending content, controlling the device, and setting up texts. "Send something" and basic device controls move to Today so users can act from the screen they check. Full device controls and text setup are in Settings.

Current pageChapters
Chapters are part of Story

Chapters and family notes belong with the photos and memories that make up the person's story. On desktop, a narrower text column makes long chapters easier to read.

Current pagesPhotos, Contribute, Activity
Photo uploads and recent memories are in the gallery

Users should be able to add photos where they view them. The gallery in Story includes uploads and recent memories, replacing separate Contribute and Activity pages. Opening a photo also gives users the option to send it to the device.

Current pageProfile
Profile stays in the main navigation

Family details, preferences, and conversation guidance need to be easy to find and update. Profile keeps its own tab, with editing by section so users can focus on the information they want to change. It also shows when the profile was saved and whether the device has retrieved it.

Current actionSign out
Account and setup options are together in Settings

Sign out moves into Settings with device controls, text setup, and the option to add the app to the phone's home screen. This gives users one place for setup and account tasks.

Current pageAdmin
Admin groups logins by person

On desktop, administrators can see which logins belong to each person receiving care. Login details open in a side panel so the list stays visible.
